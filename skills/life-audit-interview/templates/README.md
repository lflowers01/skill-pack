# life-audit

This folder holds your life audit: four rested sittings, then a check-in. Everything the interviewer knows about you lives here, not in the chat. Start a new session, invoke the life-audit-interview skill, and it reads `state.md` and picks up where you left off.

You own these files. Read, edit, or delete any of them at any time. If you edit one by hand, your version is treated as truth next time. Say "forget this" in a sitting to have a quote removed everywhere. Main outputs: `outputs/summary.md` and `outputs/commitments.md`.
